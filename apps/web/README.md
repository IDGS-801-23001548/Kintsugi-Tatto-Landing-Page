# Kintsugi Tattoo — landing

Landing estática creada con React, TypeScript y Vite.

## Requisitos

- Node.js 20 o posterior.
- npm.

## Desarrollo y compilación

```sh
npm install
npm run dev
npm run typecheck
npm run build
npm run preview
```

Vite genera el sitio estático en `dist/`, listo para publicarse en un hosting estático. La vista previa local usa rutas de ancla y no requiere servidor de aplicación.

## Versión demo

Esta compilación está poblada como demo de presentación. Los nombres, perfiles, fotografías, dirección, horario, teléfono y textos legales son ficticios. Las fotografías de artistas y tatuajes se generaron para esta demo. No uses esta información como contacto real ni como aviso legal vigente.

La descarga de Android aparece como «Próximamente», de acuerdo con el estado actual del proyecto. Los textos de servicios, estudio, proceso, app y FAQ siguen el PDF de referencia en `Context/`.
